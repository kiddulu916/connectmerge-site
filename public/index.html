The mechanic

Chain tiles. Collapse the run. Repeat.

One extra move — the chain — turns a familiar merge puzzle into something that rewards planning ahead.

1. Chain the tiles

Drag through a run of same-tier tiles — three, four, or as long as the board allows.

2. Collapse the chain

Release, and the whole run merges into the next tier up — in a single move.

3. Longer chains score more

Combo scoring rewards the reach, not just the merge. Plan long runs for the big multipliers.

4. Same board, every day

The board resets daily, identical for every player. Everyone solves the same puzzle.

The fair part

One board. One seed. Everyone.

Every player gets the exact same daily board — same tiles, same layout, same starting position. When you beat a friend's score, you're not beating a different puzzle. You're beating the same one, better.
